# Установка сервиса проверки контрагентов

Сервис по ИНН скачивает отчёты Rusprofile и Глобас, передаёт их нейросети и выдаёт заключение:
«Сотрудничество безопасно», «Требуются обеспечительные меры» или «Сотрудничество не рекомендуется».
Работает через браузер (веб-интерфейс) и через API для 1С.

Время установки — около 15 минут.

Установка на Linux-сервер — в [INSTALL-linux.md](INSTALL-linux.md).

---

## 1. Что понадобится

| | |
|---|---|
| Компьютер | Windows 10/11 или Windows Server 2016+, от 4 ГБ памяти, 1 ГБ на диске |
| Интернет | доступ к rusprofile.ru, globas.credinform.ru, routerai.ru (и/или GigaChat, Claude), pypi.org (установка библиотек) и серверы Microsoft, откуда скачивается Chromium |
| Учётки | логин и пароль Rusprofile, логин и пароль Глобаса |
| Ключ ИИ | хотя бы один: RouterAI (routerai.ru), GigaChat (developers.sber.ru) или Claude (Anthropic) |
| Права | администратора — только если нужен автозапуск при включении компьютера |

Если сервис будет работать для 1С, ставьте его на компьютер, который включён всегда (сервер),
и проверьте, что сервер 1С может до него достучаться по сети.

---

## 2. Установите Python

1. Откройте https://www.python.org/downloads/windows/ и скачайте **Python 3.12** (или новее, но не ниже 3.11),
   вариант «Windows installer (64-bit)».
2. Запустите установщик. **Внизу первого окна отметьте галочку «Add python.exe to PATH»**, затем «Install Now».
3. Проверка: откройте «Командную строку» (Win+R → `cmd` → Enter) и выполните `python --version`.
   Должно появиться `Python 3.12.x`.

---

## 3. Распакуйте сервис

Распакуйте архив `counterparty-checker.zip` в папку **без кириллицы и пробелов в пути**, например:

```
C:\counterparty-checker
```

Внутри должны быть папки `app`, `scripts`, `windows` и файлы `run.py`, `requirements.txt`, `.env.example`.

---

## 4. Запустите установку

Откройте папку `windows` и дважды щёлкните **`install.bat`**.

Скрипт сам:
- найдёт Python;
- создаст окружение `.venv` и установит библиотеки;
- скачает браузер Chromium (~150 МБ) — через него сервис заходит на Rusprofile и Глобас;
- создаст файл настроек `.env`.

В конце должно появиться **«=== Готово ===»**. Это займёт 3–10 минут в зависимости от интернета.

> **Интернет через прокси?** Откройте `cmd`, перейдите в папку и запустите установку так:
> ```
> cd C:\counterparty-checker\windows
> set HTTPS_PROXY=http://адрес-прокси:порт
> install.bat
> ```

---

## 5. Впишите логины Rusprofile и Глобаса

В корне папки откройте файл **`.env`** в Блокноте (правой кнопкой → «Открыть с помощью» → «Блокнот»)
и заполните строки:

```
RUSPROFILE_LOGIN=почта@компании.ru
RUSPROFILE_PASSWORD=пароль

GLOBAS_LOGIN=почта@компании.ru
GLOBAS_PASSWORD=пароль
```

Если сервис будет доступен другим компьютерам в сети, задайте ещё ключ доступа — без него любой,
кто откроет страницу, сможет менять настройки:

```
API_TOKEN=придумайте-длинный-пароль
```

Сохраните файл (Ctrl+S). Файл `.env` содержит пароли — не пересылайте его и не выкладывайте в общие папки.

---

## 6. Запустите сервис

Дважды щёлкните **`windows\start.bat`**. Откроется чёрное окно с журналом и через пару секунд — браузер
со страницей **http://localhost:8010/**.

- Окно `start.bat` не закрывайте: пока оно открыто, сервис работает. Остановить — Ctrl+C в этом окне.
- При первом запуске Windows может спросить разрешение для Python в брандмауэре — нажмите «Разрешить».

---

## 7. Подключите нейросеть

На странице сервиса нажмите **«Настройки ИИ»** (справа вверху; при первом запуске окно откроется само).

1. В блоке **RouterAI** вставьте API-ключ → «Сохранить ключ».
   (Или ключ GigaChat / Claude в соответствующем блоке.)
2. В разделе **«Модель для анализа»** выберите модель. Рядом указана примерная цена одной проверки.
3. Нажмите **«Проверить»** у выбранной модели — должно появиться «Работает · ответ за N с».

Добавить другие модели RouterAI можно поиском в поле «Добавить модель».

---

## 8. Первая проверка

1. Введите ИНН в поле вверху страницы (КПП — по желанию) и нажмите **«Проверить»**.
2. Ниже появятся этапы: «Скачивание отчётов» → «Анализ ИИ». Обычно 1–3 минуты.
3. Результат: итог, обеспечительные меры, основания, ссылки на скачанные PDF.

**Если при первой проверке ошибка входа на Rusprofile или Глобас** (сайт просит код из письма или капчу) —
войдите один раз вручную:

```
windows\login.bat rusprofile
windows\login.bat globas
```

Откроется окно браузера — войдите как обычно, вернитесь в чёрное окно и нажмите Enter.
Сессия сохранится, дальше сервис будет входить сам.

**Если ошибка «не удалось скачать PDF» в Глобасе** — в тексте ошибки указан путь к скриншоту в папке
`data\debug\`. Передайте скриншот разработчику: по нему настраивается кнопка выгрузки (параметр
`GLOBAS_EXPORT_STEPS` в `.env`).

---

## 9. Автозапуск (для сервера)

Чтобы сервис работал постоянно и сам запускался после перезагрузки, даже без входа пользователя:

1. Закройте окно `start.bat`, если оно открыто.
2. Правой кнопкой по **`windows\autostart-on.bat`** → **«Запуск от имени администратора»**.

Скрипт создаст задачу планировщика «CounterpartyChecker», откроет порт 8010 в брандмауэре и запустит сервис.
Журнал работы пишется в `data\service.log`.

Отключить: правой кнопкой по **`windows\autostart-off.bat`** → «Запуск от имени администратора».

> **Важно:** при автозапуске сервис работает под системной учётной записью, а при ручном — под вашей.
> Повторять ручной вход (`login.bat`) после включения автозапуска не нужно: сохранённые сессии лежат
> в папке сервиса `data\browser` и общие для обоих режимов.

---

## 10. Подключение 1С

Адрес сервиса для 1С: `http://<имя-или-IP-сервера>:8010`. Проверить доступность с сервера 1С —
открыть в браузере `http://<сервер>:8010/health`, должно вернуться `{"ok":true,...}`.

- Запрос проверки: `POST /api/v1/checks` с телом `{"ИНН": "...", "КПП": "...", "Ожидать": 240}`
- Результат: `GET /api/v1/checks/{id}`
- Если задан `API_TOKEN` — передавать заголовок `X-API-Key: <токен>`

Готовый код на встроенном языке 1С и полное описание полей ответа — в `README.md`, раздел «Пример для 1С».
Описание всех методов в браузере: `http://<сервер>:8010/docs`.

---

## 11. Обновление

1. Остановите сервис (Ctrl+C в окне `start.bat` или `autostart-off.bat`).
2. Распакуйте новый архив поверх старой папки. Папки `data` и `.venv` и файл `.env` при этом сохраняются —
   история проверок, ключи и настройки не пропадут.
3. Запустите `windows\install.bat` (доставит новые библиотеки), затем снова `start.bat` или `autostart-on.bat`.

---

## 12. Если что-то не работает

| Признак | Что делать |
|---|---|
| `install.bat`: «Не найден Python 3.11 или новее» | переустановите Python с галочкой «Add python.exe to PATH» (шаг 2) |
| `install.bat` падает на скачивании | нет доступа в интернет или нужен прокси (см. шаг 4) |
| Страница не открывается, в окне «address already in use» | порт 8010 занят: поменяйте `PORT=8010` в `.env` на другой (например 8020), а также в `autostart-on.bat` и `autostart-off.bat` |
| Вверху страницы «ИИ не подключён» | введите ключ в «Настройки ИИ» (шаг 7) |
| «Проверить» в настройках: «ключ не принят» | ключ скопирован не полностью или отозван — возьмите новый в личном кабинете |
| «недостаточно средств на балансе» | пополните баланс RouterAI |
| GigaChat: ошибка сертификата | скачайте «Russian Trusted Root CA» с https://www.gosuslugi.ru/crt и укажите путь к файлу в `.env`: `GIGACHAT_CA_BUNDLE=C:\certs\russian_trusted_root_ca.cer` |
| Ошибка входа на Rusprofile/Глобас | проверьте логин и пароль в `.env`, затем `windows\login.bat <источник>` (шаг 8) |
| 1С не достучаться до сервиса | включён ли автозапуск (он открывает порт в брандмауэре); откройте `http://<сервер>:8010/health` с сервера 1С |
| Что-то другое | пришлите разработчику текст из окна `start.bat` или файл `data\service.log` |

---

## 13. Удаление

1. Запустите `windows\autostart-off.bat` от имени администратора (если включали автозапуск).
2. Удалите папку `C:\counterparty-checker`.
