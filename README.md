# Проверка надёжности контрагента по ИНН

1С отправляет ИНН/КПП → сервис скачивает отчёты **Rusprofile** и **Глобас** в PDF → отдаёт их ИИ
(GigaChat или Claude) с промтом юриста/финаналитика → возвращает JSON с заключением.

```
1С ──POST /api/v1/checks──▶ очередь ──▶ Rusprofile PDF ┐
1С ◀──GET /api/v1/checks/id──          Глобас PDF    ┴─▶ ИИ ─▶ разбор (Итог, меры) ─▶ JSON
```

## Почему не было проблем с парсингом

HTML Rusprofile **не парсится вообще**:
- карточка ищется через JSON-поиск сайта `ajax.php?action=search` (тот же, что у строки поиска);
- отчёт берётся кнопкой «Скачать PDF» в реальном браузере (Playwright) — так же, как его скачивает человек;
- анализ PDF делает ИИ — ему не нужны распарсенные поля.

Браузер хранит профиль в `data/browser/<источник>`, поэтому вход выполняется один раз.

## Установка на Windows

Пошаговая инструкция для администратора — в [INSTALL.md](INSTALL.md). Кратко:

Нужен Python 3.11+ с [python.org](https://www.python.org/downloads/windows/) (при установке отметить «Add python.exe to PATH»).
Скопируйте папку проекта на компьютер или сервер и запустите файлы из папки `windows\`:

| Файл | Что делает |
|---|---|
| `install.bat` | создаёт `.venv`, ставит зависимости и Chromium (внутрь `.venv`), создаёт `.env` из шаблона |
| `start.bat` | запускает сервис в окне и открывает интерфейс в браузере; остановить — Ctrl+C |
| `autostart-on.bat` | *от имени администратора*: запуск при включении компьютера (задача планировщика под SYSTEM, работает без входа пользователя) и открытие порта 8010 в брандмауэре для 1С; журнал — `data\service.log` |
| `autostart-off.bat` | *от имени администратора*: убирает автозапуск и останавливает сервис |
| `login.bat rusprofile` | ручной вход в источник, если сайт просит код из письма или капчу |

Через прокси перед `install.bat` выполните `set HTTPS_PROXY=http://прокси:порт`.
Если меняете порт — поправьте `PORT` в `.env` и в `autostart-on.bat` / `autostart-off.bat`.

На Windows запускайте сервис только через `run.py` (это делают bat-файлы), а не `uvicorn --reload`:
в режиме `--reload` на Windows Playwright не может запустить браузер.

## Установка на Linux-сервер / macOS

Пошаговая инструкция — в [INSTALL-linux.md](INSTALL-linux.md). Скрипты лежат в папке `linux/`:

| Файл | Что делает |
|---|---|
| `bash linux/install.sh` | ставит Python 3.11+ и библиотеки Chromium через sudo (Ubuntu/Debian, RHEL/Alma/Rocky), создаёт `.venv`, зависимости, Chromium (внутрь `.venv`), `.env` со сгенерированным `API_TOKEN`; в конце проверяет, что Chromium запускается |
| `bash linux/run.sh` | запуск в консоли; остановить — Ctrl+C |
| `sudo bash linux/autostart-on.sh` | служба systemd `counterparty-checker`: запуск при загрузке, перезапуск при сбое, порт в ufw/firewalld; работает от владельца папки (другой — `SERVICE_USER=имя`) |
| `sudo bash linux/autostart-off.sh` | останавливает и удаляет службу |
| `bash linux/logs.sh` | журнал службы (`journalctl`) |
| `bash linux/login.sh rusprofile` | ручной вход в источник; нужен экран (`ssh -X`) или профиль, скопированный из `data/browser/<источник>` с другого компьютера |

`SKIP_SYSTEM_DEPS=1 bash linux/install.sh` — не трогать системные пакеты. Порт берётся из `PORT` в `.env`.

Заполнить `.env` (шаблон — `.env.example`): учётки источников и ключ хотя бы одного ИИ:
- **GigaChat** — `GIGACHAT_AUTH_KEY` («Ключ авторизации» из developers.sber.ru), `GIGACHAT_SCOPE`
  (`GIGACHAT_API_CORP` для юрлица по договору, `GIGACHAT_API_PERS` для физлица). API Сбера использует
  сертификат НУЦ Минцифры: скачайте `russian_trusted_root_ca.cer` с gosuslugi.ru/crt и укажите путь в `GIGACHAT_CA_BUNDLE`.
- **Claude** — `ANTHROPIC_API_KEY`. PDF передаются как есть (модель видит таблицы).

- **RouterAI** — `ROUTERAI_API_KEY` с routerai.ru, модели перечисляются в `ROUTERAI_MODELS`
  (по умолчанию `qwen/qwen3.8-27b` и `deepseek/deepseek-v4-pro-0813`). Модели текстовые — сервис передаёт им
  извлечённый из PDF текст (~25 тыс. токенов на проверку). Каждая модель из списка появляется в интерфейсе отдельно;
  в API — `"ИИ": "routerai:deepseek/deepseek-v4-pro-0813"`.

Ключи и модель по умолчанию удобнее задавать в веб-интерфейсе — кнопка **«Настройки ИИ»**: там же проверка подключения,
поиск моделей по каталогу RouterAI с ценой одной проверки и выбор модели для анализа. Сохранённое в интерфейсе
хранится в `data/ai_settings.json` (имеет приоритет над `.env`) и применяется без перезапуска.
Если сервис доступен в сети, задайте `API_TOKEN` — иначе менять ключи сможет любой, кто откроет страницу.

`AI_PROVIDER=auto` берёт первый настроенный; в запросе можно указать `"ИИ": "gigachat"` / `"anthropic"`.

## Первый запуск

1. Проверить ИИ и промт на уже скачанных файлах (без сайтов):
   ```bash
   .venv/bin/python -m scripts.analyze_local samples/globas_1655503631.pdf samples/rusprofile_1655503631.pdf
   ```
2. Если автоматический вход не прошёл (код из письма, капча) — войти вручную один раз:
   ```bash
   .venv/bin/python -m scripts.login rusprofile
   ```
3. Запустить сервис (на Windows — `windows\start.bat`):
   ```bash
   .venv/bin/python run.py --open
   ```
   Интерфейс: `http://сервер:8010/`, документация API: `http://сервер:8010/docs`.

### Глобас: настройка выгрузки

Вход и поиск по ИНН работают по известной форме (`#LoginName`, `#Password`). Кнопку выгрузки PDF на карточке
сервис ищет по текстам «Выгрузка», «Скачать отчёт», «Экспорт», «PDF» и подтверждает диалог формата.
Если в вашем интерфейсе иначе — при ошибке сервис сохраняет скриншот и HTML в `data/debug/`;
по ним задайте точную последовательность кликов, например:

```
GLOBAS_EXPORT_STEPS=text=Выгрузка;label:has-text("PDF");button:has-text("Сформировать")
```

Быстрее всего записать клики через `.venv/bin/playwright codegen https://globas.credinform.ru`.
То же для поиска: если внутри системы другая страница результатов, поменяйте `GLOBAS_SEARCH_PATH`.

## Веб-интерфейс

Открыть `http://сервер:8010/` в браузере:
- ввод ИНН/КПП с проверкой контрольной суммы; реквизиты можно вставить одной строкой («ИНН 1655503631 КПП 165501001»);
- ход проверки по этапам с таймером — страницу можно закрыть, результат останется в истории;
- крупный итог, обеспечительные меры, основания, подписант, ссылки на исходные PDF;
- копирование заключения или JSON, печать, повторная проверка;
- история слева с поиском по ИНН и названию; у каждой проверки своя ссылка (`/#id`) — её можно переслать коллеге.

Если в `.env` задан `API_TOKEN`, страница один раз попросит ключ и запомнит его в браузере.

## API

Заголовок `X-API-Key: <API_TOKEN>` (если задан в `.env`).

### `POST /api/v1/checks`

```json
{"ИНН": "1655503631", "КПП": "165501001", "Ожидать": 0, "Принудительно": false}
```

| Поле | |
|---|---|
| `ИНН`, `КПП` | реквизиты (ИНН проверяется по контрольной сумме) |
| `Ожидать` | сколько секунд держать запрос до результата (0 — сразу вернуть `id`) |
| `Принудительно` | не брать готовое заключение за последние `CACHE_HOURS` часов |
| `ИИ` | `gigachat` / `anthropic` / `routerai:<модель>` (необязательно) |
| `КонтекстСделки` | заменить контекст сделки в промте (необязательно) |

Проверка занимает 1–3 минуты, поэтому 1С обычно создаёт задачу и опрашивает её.

### `GET /api/v1/checks/{id}`

`Статус`: `queued` → `running` (`Этап` подскажет, что происходит) → `done` | `error` (`Ошибка`).

```json
{
  "id": "90e1…",
  "Статус": "done",
  "Контрагент": "ООО \"Смарт Учет+\"",
  "ИНН": "1655503631",
  "КПП": "165501001",
  "ДатаФормированияЗаключения": "2026-10-21T10:31:05",
  "ТекстЗаключения": "**Основания для заключения:** …",
  "ИИ/МодельИИ": "GigaChat / GigaChat-2-Max",
  "ИИ": "GigaChat",
  "МодельИИ": "GigaChat-2-Max",
  "Основания": "…",
  "Итог": "Требуются обеспечительные меры",
  "ИтогТекст": "…",
  "ОбеспечительныеМеры": ["Банковская гарантия", "Аккредитив"],
  "Подписант": "…",
  "ФайлыПроверки": ["Rusprofile_1655503631.pdf", "Globas_1655503631.pdf"],
  "Предупреждения": []
}
```

`Итог` всегда один из трёх вариантов (или пусто, если ИИ ответил не по формату — тогда есть предупреждение).
Если один из источников недоступен, анализ идёт по второму, причина — в `Предупреждения`.

### `GET /api/v1/checks?q=&limit=` — история проверок (поиск по ИНН или названию).

### `DELETE /api/v1/checks/{id}` — удалить проверку вместе со скачанными отчётами (выполняющуюся — нельзя, 409).

### `GET /api/v1/checks/{id}/files/{имя}` — скачать исходный PDF (например, приложить к карточке контрагента).

## Структура

```
app/main.py            API для 1С
app/service.py         очередь и конвейер проверки
app/store.py           SQLite: задачи и результаты (data/checks.sqlite)
app/sources/           Rusprofile, Глобас (Playwright)
app/ai/                промт, GigaChat, Claude, разбор ответа
scripts/login.py       ручной вход в источник
scripts/analyze_local.py  анализ готовых PDF
```

Проверки выполняются по одной (очередь), источники внутри проверки — параллельно.
